# Lucide shell icons

Source: https://github.com/lucide-icons/lucide

Pinned commit: `70562c1ee1c4fdcf736fe97bc893fb8511927934`

Only icons used by ShellIcon are included. SVGs are unmodified upstream files.
See LICENSE for attribution and redistribution terms.

`bounds.js` records horizontal artwork bounds for content-hugging icons.
Regenerate it after adding or updating SVGs with `python3 update-bounds.py`
(requires rsvg-convert and Pillow for development only).
